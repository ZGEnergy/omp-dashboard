# session-file-reader.ts — index

Standalone JSONL session reader. Skips title metadata before canonical session header. Exports `SessionEntry`, `loadSessionEntries(filePath)` (leaf→root branch order via parentId), `createBranchedSessionFile(sessionFilePath, targetEntryId)` for fork-from-message. Linear fallback when no tree structure. Exports `findSessionToolCallPayload(filePath, toolCallId)` → `{ content?, edits? } | null`: scans `message.content[]` for `{ type:"toolCall", id === toolCallId }` (nested id, not entry top-level), returns `arguments.content` (Write) / `arguments.edits` (Edit) from the on-disk JSONL — the FULL untruncated payload surviving the in-memory ~4 KB cap / >20-op collapse. SECURITY: takes only a transcript path + a toolCallId used for equality (no path input, no traversal); missing file / unknown id / unparseable → null, no path fallback. Backs `GET /api/session-change`. See change: opt-in-out-of-cwd-session-diffs. `createBranchedSessionFile` skips the title preamble too (was: asserted index 0 is `session`, so it threw `Invalid session file: missing header` on every current-format file) and re-emits preamble lines verbatim — title `pad` is a fixed-width slot pi rewrites in place. See change: fork-action-opens-an-empty-chat.
