# session-api.ts — index

REST wrappers for session control. Exports `registerSessionApi(fastify, deps)`. Routes: `/api/session/:id/{prompt,abort,shutdown,rename,hide,unhide,resume,flow-control,model,thinking-level,attach-proposal,detach-proposal}` and `/api/session/spawn`. Tags user-resume intent; handles fork-empty-session degrade. Fork preflight MUST stay in parity with `browser-handlers/session-action-handler.ts`: missing JSONL + no content → degrade (`FORK_DEGRADED_TO_NEW`, 200); missing JSONL + content → 409 `FORK_SOURCE_UNAVAILABLE`, spawns nothing. Sets/clears `resuming` around every fork exit. `SessionApiDeps.eventStore?` (wired in `server.ts`) feeds the preflight's `hasConversationEvents(id)` backstop — required for parity, since a reattached session's counters are zeroed and an old bridge sends no `firstMessage`. See change: fork-action-opens-an-empty-chat, fork-content-predicate.
